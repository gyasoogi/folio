# Folio — Personal Knowledge Space

화이트 & 블랙 기반의 개인용 지식 관리 웹앱 초기 버전입니다. 외부 라이브러리나 빌드 도구 없이 실행되는 단일 HTML 앱입니다.

## 실행 방법

1. `index.html`을 Chrome, Edge, Safari 등 최신 브라우저에서 엽니다.
2. 더 안정적인 저장소 동작을 원하면 프로젝트 폴더에서 로컬 정적 서버를 실행한 뒤 해당 주소로 접속하세요. 예: `python -m http.server 8000` 후 `http://localhost:8000`.
3. 데이터는 브라우저의 IndexedDB에 저장됩니다. 브라우저 저장 공간을 지우면 데이터가 삭제될 수 있으므로 Settings & data에서 백업 파일을 정기적으로 내보내세요.

## 포함된 기능

- 대시보드와 최근 기록
- 퀵 메모 생성 및 문서로 전환
- 문서 제목/본문 편집과 자동 저장
- 태그 및 카테고리
- 제목·본문·태그·카테고리·첨부 링크를 대상으로 하는 기본 검색
- 내부 문서 연결과 자동 백링크
- 문서/메모를 참조하는 보드 카드 추가, 카드 드래그 배치, 캔버스 이동·확대/축소, 카드 간 시각적 연결
- URL 및 파일 첨부
- JSON 백업 내보내기와 복원
- PC·모바일 반응형 UI

## 현재 버전의 범위와 한계

- 로그인, 서버 저장, 기기 간 동기화, 실시간 협업은 아직 구현되지 않았습니다.
- URL 제목/썸네일 자동 미리보기, 외부 서비스 본문 가져오기, 전체 텍스트 첨부 파일 검색은 포함되지 않았습니다.
- 첨부 파일은 브라우저 저장 공간을 사용하며 파일당 30MB 제한을 적용합니다. 전체 저장 용량은 브라우저와 기기 환경에 따라 달라집니다.
- 문서 본문은 기본 텍스트 편집기이며 고급 리치 텍스트 편집과 전체 버전 이력은 후속 작업 대상입니다.
- 여러 탭/기기 동시 편집 충돌 감지는 구현되지 않았습니다.

실제 서비스로 배포하려면 인증, 서버 데이터베이스, 파일 스토리지, 접근 제어, 서버 측 백업과 동기화를 별도 구현해야 합니다.
